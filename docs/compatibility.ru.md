## Сборка

Запускай `./gradlew build` из нужной папки. На Windows — `gradlew.bat build`. Для самого Gradle нужен JDK 21 при использовании Gradle 8 или JDK 25 при использовании Gradle 9; версия Gradle указана в `gradle/wrapper/gradle-wrapper.properties`.

Компиляция проектов до Minecraft 1.20.4 включительно использует JDK 17, для 1.20.5–1.21.11 — JDK 21, для 26.x — JDK 25. Эти JDK должны быть установлены как Gradle toolchains. Для инструментов сборки старых NeoForge-проектов дополнительно нужен JDK 21. Выходной байткод соответствует Java из таблицы, включая Java 8 для 1.16.5.

Из корня репозитория можно собрать один вариант:

```sh
python3 tools/build.py --target fabric-26.3
```

Без `--target` собираются все доступные варианты. Параметры `--jdk-21`, `--jdk-25` и повторяемый `--toolchain` принимают пути к установленным JDK. Например:

```sh
python3 tools/build.py --target forge-1.20.1 --jdk-25 /path/to/jdk25 --toolchain /path/to/jdk17
```

Скрипт запускает сборку и проверки Gradle, затем собирает готовые JAR в `dist/social-rating-1.0.0/` вместе с контрольными суммами. Добавь `--changed`, чтобы пересобирать только варианты с изменёнными исходниками или JAR; для остальных сохраняется проверка содержимого и контрольных сумм. `--collect-only` повторно проверяет и копирует уже собранные файлы, если их содержимое и исходники не изменились после успешной сборки. `--list` выводит доступные варианты.
